# Instagram Stories

A simplified Instagram Stories feature built with pure HTML, CSS & JavaScript — no external libraries.

**[Live Demo](https://jyoti-131.github.io/instagram-stories)**


## ✨ Features

- 📜 Horizontally scrollable story list
- ⏱️ Auto-advances every 5 seconds
- 👆 Tap left / right to navigate
- ⏸️ Long press to pause
- 💫 Smooth crossfade transitions
- 🔄 Loading states handled
- 👁️ Seen / unseen story indicator
